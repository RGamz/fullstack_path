    How to use this plan

    Learn a chunk, then build. Every module is split into parts. Each part has a few lessons and ends with a project that uses exactly what those lessons taught. Do the project before moving on: that's where the learning sticks.

    Each lesson: read the theory and type out the code examples yourself → if something is unclear, watch a video (the link opens a YouTube search; pick a recent, well-rated result) and check the docs → do the exercises. Tick off exercises as you go, then tick the lesson.

    Each project: open "Read the full brief", follow the steps in order and commit to git after each one. The project is finished when every "Done when" box is ticked. Push it to GitHub and paste the link into the card.

    "Continue" at the top always jumps to the next lesson or project you haven't finished.

    How long it takes: roughly 500–700 hours in total, and most of that is the projects. At 6–8 hours a week that's about 15–20 months; at 12–15 hours a week, about 9–12 months. The week estimates on each module assume about 10 hours a week. Example week: 3 weekday evenings × 1 h (theory + exercises), and a 3–4 h weekend block for project work.

    Going faster: when a part has two projects, doing one well is enough to move on; come back to the other later if you want more practice. Skip the stretch goals on a first pass.

    Free companions: Full Stack Open (University of Helsinki: React, Node, Express, MongoDB, testing, TypeScript), The Odin Project – Full Stack JavaScript, Learn Next.js and roadmap.sh.
